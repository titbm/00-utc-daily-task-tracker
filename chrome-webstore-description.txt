# 00 UTC | Daily Task Tracker

## Short description
Track and manage your daily internet tasks with automatic restoration at midnight UTC. Organize web pages you need to visit daily with bookmark-based storage.

## Full description
00 UTC | Daily Task Tracker is a Chrome extension that helps you stay productive by tracking and managing your daily web tasks. All your tasks are stored as bookmarks and automatically reset at midnight UTC or after a custom interval. No external servers or accounts required — everything is local and private.

**Features:**
- Bookmark-based storage: all tasks live in Chrome bookmarks
- Automatic restoration: tasks reset at 00:00 UTC or after a custom interval
- Quick add: right-click context menu or popup button
- Side panel UI: manage active and completed tasks
- Task cycles: open all tasks sequentially with one click
- Beautiful highlight animations (RoughNotation-inspired)
- Smart banners: reminder when you have pending tasks
- No data collection, no ads, no tracking

**How it works:**
1. Add any page as a daily task via right-click or popup
2. Reorder your tasks in the side panel by simply dragging and dropping them — the order is saved and used for task cycles
3. For each task, choose when it should return to active: at midnight UTC or after a custom interval (1h, 3h, 6h, 12h, 24h)
4. Click "Start" to begin your task cycle — each task opens in a new tab, in your chosen order
5. Close the tab when done; the task will be marked as completed, and the next task in your queue will open automatically — repeat until all tasks are completed
6. Completed tasks will automatically return to active at the time you selected, or you can restore them manually from the side panel at any time

**Permissions:**
- activeTab: detect when you open/close task tabs during cycles
- bookmarks: store and manage your tasks
- storage: save extension settings
- tabs: open/close tabs for task cycle
- contextMenus: add right-click menu
- sidePanel: show side panel UI
- alarms: schedule automatic restoration
- management: detect extension enable/disable events
- host_permissions (<all_urls>): show reminder banner on all web pages when you have pending tasks

**Privacy:**
- No personal data is collected or sent anywhere
- All data is stored locally in your browser
